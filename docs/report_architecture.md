# Report Architecture

## Primary Report Pages

The PBIX contains four main business-facing pages plus supporting
tooltip pages.

### 1. PROJECT HUB

Purpose: - Establish the business problem - Define project objectives -
Explain the report structure - Frame the strategic value of the analysis

### 2. MENU & PORTFOLIO

Purpose: - Executive analytical overview - Monitor portfolio KPIs -
Compare city and cuisine performance - Evaluate price-tier behavior -
Quantify Product Strategy segments - Benchmark restaurant performance

This is the **primary analytical dashboard** and the page featured in
the GitHub README.

### 3. ACTIONS

Purpose: - Translate evidence into executive recommendations - Group
actions across growth, portfolio optimization, market expansion and
operational excellence - Make the analysis decision-oriented rather than
descriptive

### 4. SEGMENTS

Purpose: - Explain Price Tier definitions - Explain Popularity Segment
thresholds - Document the Product Strategy logic - Connect analytical
classification to strategic action

## Supporting Tooltip Pages

The PBIX also contains tooltip pages used to support interactive visual
exploration. These are implementation details and are not treated as
primary business-facing report pages.

## Visual Design Philosophy

The report uses a consistent Zomato-inspired visual language:

-   Red / pale-pink / white palette
-   Strong left navigation rail
-   Rounded analytical cards
-   KPI-first hierarchy
-   Consistent typography
-   Clear segmentation labels
-   Dense but structured analytical layout

The design prioritizes **decision density without sacrificing
navigability**.
