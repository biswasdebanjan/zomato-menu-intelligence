# Power BI File

The Power BI Desktop source file is included in this directory.

**File:** `Zomato_Menu_Intelligence_Portfolio_Strategy.pbix`

The report contains the Project Hub, Menu & Portfolio, Actions and
Segments pages, plus supporting tooltip pages.

Open the PBIX in Power BI Desktop to inspect the Power Query layer,
single-table model, calculated columns, DAX measures and report
interactions.
